# Simple Calculator

A lightweight, responsive calculator built with HTML, CSS, and JavaScript.

## Features

✨ **Clean & Modern UI** - Centered calculator with rounded corners and shadow effects
🔢 **Number Buttons** - Support for digits 0-9
➕ **Basic Operations** - Addition (+), Subtraction (-), Multiplication (*), and Division (/)
🔄 **Clear Function** - "C" button to reset the calculator display
🧮 **Calculate Results** - "=" button to compute expressions
⚠️ **Error Handling** - Shows "Error" for invalid expressions
📱 **Responsive Design** - Works seamlessly on different screen sizes and devices
🎨 **Styled Buttons** - Different colors for operation buttons for better UX

## How to Use

1. Open `calculator.html` in any web browser
2. Click number buttons to input values
3. Click operation buttons (+, -, *, /) to perform calculations
4. Click "=" to see the result
5. Click "C" to clear the display and start over

## Installation

Clone the repository:
```bash
git clone https://github.com/krunal-ux/simple-calc.git
cd simple-calc
```

Open the calculator:
```bash
open calculator.html
```

Or simply double-click `calculator.html` in your file explorer.
